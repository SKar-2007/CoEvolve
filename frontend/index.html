WHY COEVOLVE

ADVERSARIAL
CO-EVOLUTION

Traditional security tools play defense. CoEvolve pits two AI agents against each other in an arms race that gets stronger every iteration.

ATTACKER AGENT

Generates adversarial tasks across 10+ vulnerability classes with adaptive difficulty scaling.

DEVELOPER AGENT

ReAct tool-use agent with 7 tools: read, write, shell, search, tests, git. Builds patches autonomously.

HYBRID JUDGE

Two-stage evaluation: Semgrep SAST scanning + dynamic DAST exploit replay against live apps.

DISTILLER AGENT

Converts failure traces into imperative security rules. Auto-registers new patterns for future episodes.

ELO RATING

Zero-sum adaptive difficulty matching across 10 tiers. Attacker and defender ratings evolve in real-time.

MULTI-LANGUAGE

19 vulnerable apps across Python, JavaScript, and Java. SAST rules for all three languages.
