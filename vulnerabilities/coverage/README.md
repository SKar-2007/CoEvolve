# Vulnerability Coverage

Tracks detection and mitigation coverage across all vulnerability classes.

## Structure

```
coverage/
  metrics.json       # Overall coverage metrics
  by-class.json      # Per-class coverage breakdown
  history.json       # Coverage over time
```

## Metrics

- **Detection Rate**: % of vulnerabilities correctly identified
- **Mitigation Rate**: % of vulnerabilities successfully patched
- **Rule Coverage**: % of vulnerability classes with distilled rules
- **Test Coverage**: % of vulnerability classes with test cases
