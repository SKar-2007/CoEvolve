# Prompt History

This directory tracks the evolution of agent prompts over time.

## Format

Each file is named `v{version}_{timestamp}.md` and contains a snapshot of all prompts at that version.

## Versioning

- Version numbers increment when prompts are modified
- Timestamps use ISO 8601 format
- Current version is always available in `prompts/current/`

## Entries

| Version | Date | Description |
|---------|------|-------------|
| v1 | 2026-09-12 | Initial prompt set for attacker, developer, distiller, and judge agents |
